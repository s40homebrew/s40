# Hello: native display and input

A small example using the shared launcher and C API.

Build from the repo root with `bash homebrew/build.sh hello`. Install
`homebrew/dist/hello/S40Hello.jar` and its matching JAD.

Choose **Check firmware**, then **Start**. The native app displays a square:

- D-pad moves it.
- Center or Space changes its color.
- Right softkey returns to the Java launcher.
